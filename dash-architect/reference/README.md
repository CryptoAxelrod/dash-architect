# Dash Architect — демо-надстройка для Excel

Демо без реальной логики: что бы ни выбрали в панели, кнопка **Generate dashboard** показывает один и тот же готовый дашборд внутри книги.

## Как это устроено

Боковая панель — обычная task pane надстройка (`manifest.xml`).

Объект с HTML внутри листа, который можно двигать и растягивать, в Excel называется **content add-in** (надстройка содержимого). Это отдельный тип надстройки: Microsoft не даёт объединить его с боковой панелью в одном манифесте, и в Office.js нет команды, которая вставляет его в лист из кода. Поэтому он лежит отдельно (`manifest-viewer.xml`), а демо устроено как фокус:

1. В книге заранее есть **скрытый** лист `Dashboard`, на который один раз вручную вставлен дашборд.
2. Кнопка проигрывает «сборку» (Reading rows… Drawing the chart…), затем показывает этот лист, ставит его сразу после листа с данными и открывает. Для зрителя это выглядит как только что созданный лист.
3. Если скрытого листа нет, кнопка создаст пустой лист `Dashboard` и подскажет, что вставить на него Viewer.

## Файлы

- `manifest.xml` — боковая панель Dash Architect (кнопка на вкладке «Главная»)
- `manifest-viewer.xml` — Dash Architect Viewer, дашборд внутри листа
- `taskpane.html`, `taskpane.css`, `taskpane.js` — панель
- `dashboard.html` — ваш дашборд (добавлено только подключение Office.js)
- `commands.html`, `assets/` — служебная страница и иконки
- `Store sales 2025.xlsx` — книга с теми же 300 продажами, что в дашборде

## 1. Разместить файлы на HTTPS

Надстройки Office грузятся только по HTTPS. Проще всего бесплатно через GitHub Pages:

1. На github.com создайте публичный репозиторий `dash-architect`.
2. **Add file → Upload files** — перетащите всё содержимое папки, вместе с папкой `assets`.
3. **Settings → Pages → Deploy from a branch → main / (root) → Save**.
4. Через пару минут откройте `https://ВАШ-НИК.github.io/dash-architect/taskpane.html`. Должна открыться панель: в обычном браузере она работает в режиме превью.

Подойдёт и любой другой статический хостинг с HTTPS, тогда в шаге 2 подставьте его адрес.

## 2. Прописать адрес в манифестах

В `manifest.xml` и `manifest-viewer.xml` замените все `YOUR-GITHUB-NAME` на свой ник GitHub (поиск и замена, «Заменить все»). Эти два файла нужны локально для установки.

## 3. Установить обе надстройки

**Excel на Windows**

1. Создайте папку, например `C:\DashArchitect`, положите в неё оба манифеста.
2. ПКМ по папке → Свойства → Доступ → «Открыть общий доступ к этой папке». Сетевой путь будет вида `\\ИМЯ-КОМПЬЮТЕРА\DashArchitect`.
3. Excel → Файл → Параметры → Центр управления безопасностью → Параметры центра управления безопасностью → Каталоги доверенных надстроек. Вставьте сетевой путь → «Добавить каталог» → галочка «Показывать в меню» → ОК. Перезапустите Excel.
4. Вставка → Мои надстройки → вкладка «Общая папка» → Dash Architect → Добавить.

**Excel на Mac**

1. Finder → Cmd+Shift+G → `~/Library/Containers/com.microsoft.Excel/Data/Documents/`
2. Создайте там папку `wef` (если её нет) и скопируйте в неё оба манифеста.
3. Перезапустите Excel → Вставка → Надстройки → стрелка у «Мои надстройки».

**Excel в браузере**

В меню надстроек выберите «Загрузить мою надстройку» (Upload My Add-in) и загрузите оба манифеста по очереди. Расположение пункта Microsoft периодически меняет.

После установки на вкладке «Главная» появится кнопка **Dash Architect**.

## 4. Подготовить книгу для съёмки (один раз)

1. Откройте `Store sales 2025.xlsx`.
2. Добавьте лист и назовите его ровно `Dashboard`.
3. На нём: Вставка → Мои надстройки → **Dash Architect Viewer**. Появится объект с дашбордом. Поставьте его в левый верхний угол и растяните под размер экрана.
4. ПКМ по ярлыку `Dashboard` → Скрыть. Вернитесь на лист `Store sales` и сохраните книгу.
5. Один раз прогоните демо целиком и убедитесь, что после показа листа дашборд прогрузился.

## 5. Сценарий демо

1. Главная → **Dash Architect**.
2. **Select range** → выделите таблицу на листе (поле обновляется вживую) → **Done**. Панель покажет число строк и найденные заголовки.
3. Отметьте компоненты — схемы в карточках «достраиваются».
4. **Generate dashboard** → появляется лист с дашбордом.

**Сброс для следующего дубля:** дважды щёлкните по логотипу в панели. Лист `Dashboard` снова скроется, панель очистится. Этого нет в интерфейсе, в кадре не видно.

## Если что-то не так

- **После правок файлов панель старая.** Office кэширует надстройки. На Windows: Каталоги доверенных надстроек → галочка про очистку кэша веб-надстроек при следующем запуске → перезапуск Excel.
- **На листе серый прямоугольник вместо дашборда.** Viewer не установлен на этом компьютере или в манифесте неверный адрес. Проверьте, что `https://ВАШ-НИК.github.io/dash-architect/dashboard.html` открывается в браузере.
- **Панель пишет «Added the Dashboard sheet…».** В книге нет листа с именем ровно `Dashboard`. Имя можно поменять в `taskpane.js`, строка `dashboardSheet`.
- Нужен Excel из Microsoft 365 или 2021/2024. В старых 2016/2019 панель может отображаться некорректно.
